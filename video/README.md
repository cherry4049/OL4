# Video Folder

This folder contains the **project demonstration video** for the project.

---

## Typical Files

### 1. `demo.mp4` or `.mov`

- **Purpose:** Shows the robot navigating the environment in Webots.
- Must include:
  - Robot performing all implemented behaviours
  - Evidence of FSM / sensor integration
  - Team members speaking or narrating their contributions
- Suggested length: ~5 minutes

### 2. Optional Supporting Clips

- If multiple clips are recorded separately, include them here.
- Example: sensor tests, movement tests, code walkthrough snippets.

---

## Notes

- Only one team member should finalize and merge clips to avoid inconsistencies.
- Keep video formats standard (MP4 preferred) for easy playback by markers.
