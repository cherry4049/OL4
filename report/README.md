# Report Folder

This folder contains all **project documentation** for the Maze Robot project.

---

## Typical Files

### 1. `pitch_document.docx`

- **Purpose:** Initial project pitch submitted in Week 6.
- Includes:
  - Project idea and goals
  - Robot type and features
  - Planned system architecture
  - Preliminary task breakdown

### 2. `final_report.docx`

- **Purpose:** Comprehensive final project report submitted by 9:00am on Monday of Week 12.
- Includes:
  - Project overview and objectives
  - Technical requirements compliance
  - System architecture and behaviour model
  - Sensor processing and safety mechanisms
  - Code structure and key snippets
  - Results, demonstration summary, and individual contributions

---

## Notes

- Only one team member should update the report at a time to avoid version conflicts.
